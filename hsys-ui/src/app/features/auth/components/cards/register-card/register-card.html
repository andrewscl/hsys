Registro de usuarios

El nombre de usuario es obligatorio. Mínimo 3 caracteres.
El correo es obligatorio. Ingresa un formato de correo válido.
La contraseña es obligatoria. Debe tener al menos 8 carácteres.
El nombre de empresa es obligatorio. Debe tener al menos 2 carácteres.
El Rut de la empresa es obligatorio. El Rut debe tener 9 carácteres.
